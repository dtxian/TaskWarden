# 06 · Qt 迁移执行计划（最终方案）

> **2026-10-29 最终决定：桌面壳用 Qt 6 Widgets（C++20），引擎保留 Rust，编译成静态库经 C ABI 链接。**
> ZSUI / Iced 方案保留为历史评估（`01`、`05`、`adr/0001`），不再推进。

---

## 0. 为什么是这个组合

| 目标 | Qt + Rust 静态库 |
|---|---|
| 单进程、无 WebView2 | ✅ 一个 exe 进程（被守护任务除外） |
| 内存/CPU 小 | ✅ 实测空窗口 + 日志框：**38MB / 7.3MB private** |
| 界面好写 | ✅ 托盘、关闭到托盘、日志框、卡片、表单、单实例全是 Qt 现成能力 |
| 不重写引擎 | ✅ 3,432 行 Rust 原样搬，24 个测试保留 |
| 构建 | ✅ MSVC 2022 + CMake 4.4 + Qt 6.9.3 + Rust 1.98（均已装好并验证） |

代价：两门语言（C++ + Rust）、一层 C ABI、Qt LGPL 动态链接（要带 Qt DLL，附声明）。

## 3. 架构

```
┌──────────────────────────── Qt 6 Widgets（C++20） ────────────────────────────┐
│ MainWindow / TaskCard / LogPanel / TaskDialog / QSystemTrayIcon / QSplitter    │
│        │  QTimer 250ms 拉快照（JSON）        ▲ 用户操作                         │
│        ▼                                    │                                  │
│ EngineClient（C ABI 包装，只碰 UTF-8 字符串）                                  │
└─────────────────────────────────────────────┼──────────────────────────────────┘
                                              │ extern "C"
┌──────────────────────────── Rust staticlib ─┼──────────────────────────────────┐
│ ffi.rs（catch_unwind + last_error）          │                                  │
│   ├─ Command 通道 try_send ──► supervisor（250ms tick，唯一状态机）             │
│   ├─ events 线程 ──► 日志/notice 环形缓冲                                     │
│   └─ snapshot 读写锁 ──► tw_snapshot_json                                      │
│ core/ runtime/ infra/ 原样复用（Job Object、编码、熔断、DAG、落盘）             │
└────────────────────────────────────────────────────────────────────────────────┘
```

- **单进程**：Rust 是静态库，不另起进程。
- **不回调**：C++ 每 250ms 主动拉一次，避免 Rust 线程直接碰 Qt 对象。
- **JSON 边界**：快照/日志/通知都用 UTF-8 JSON；C++ 用 `QJsonDocument` 解析。4Hz 下开销可忽略。
- **panic=unwind**：必须保留（supervisor 依赖 `catch_unwind`）；FFI 入口再包一层。

## 4. C ABI 契约（`engine/src/ffi.rs`）

```c
typedef struct TwEngine TwEngine;

TwEngine*   tw_engine_new(const char* data_dir_utf8);   // 失败返回 NULL
void        tw_engine_free(TwEngine*);                  // 同步 shutdown
const char* tw_last_error(TwEngine*);                   // 线程内有效

int32_t tw_start(TwEngine*, const char* task_id);
int32_t tw_stop(TwEngine*, const char* task_id);
int32_t tw_restart(TwEngine*, const char* task_id);
int32_t tw_start_all(TwEngine*);
int32_t tw_stop_all(TwEngine*);
int32_t tw_crash(TwEngine*, const char* task_id);
int32_t tw_reset_breaker(TwEngine*, const char* task_id);
int32_t tw_add_task(TwEngine*, const char* cfg_json);     // snake_case TaskConfig
int32_t tw_update_task(TwEngine*, const char* cfg_json);
int32_t tw_remove_task(TwEngine*, const char* task_id);
int32_t tw_set_fault_inject(TwEngine*, int32_t flag);
int32_t tw_clear_logs(TwEngine*, const char* task_id);
int32_t tw_shutdown(TwEngine*);

char*  tw_snapshot_json(TwEngine*);                       // 调用方 tw_free_string
char*  tw_logs_json(TwEngine*, const char* task_id, uint32_t limit);
char*  tw_notices_json(TwEngine*);                        // 取走并清空
void   tw_free_string(char*);
```

实现要点：

- 所有入口 `catch_unwind`；panic → 写 `last_error`，返回 `-1`，绝不让 panic 跨 FFI。
- 命令用 `try_send`，队列满返回 `-2`，不阻塞 UI。
- `snapshot_json` 的 shape 复用现有 `SnapshotDto`（camelCase），字段与 `src/sim/useSimulator.ts` 的 `SimTask/LogLine/Metrics` 对齐。
- `cfg_json` 用现有 `TaskConfig` snake_case（`graceful_timeout`、`health:{mode,target}`）。
- `tw_engine_new` 接收 `<exe 目录>\data`，内部保留现有便携 + `%APPDATA%` 一次性迁移 + TOML 原子落盘逻辑。

## 5. Qt 壳实现要点

| 功能 | 实现 |
|---|---|
| 托盘 | `QSystemTrayIcon` + `QMenu`；图标来自 qrc（`QIcon(":/icons/tray.png")`），**不需要磁盘文件** |
| 关闭到托盘 | `MainWindow::closeEvent` → `ignore()` + `hide()`；托盘菜单「显示主窗口 / 退出」 |
| 退出 | 托盘菜单调 `tw_shutdown` + `qApp->quit()` |
| 单实例 | `QLocalServer`/`QLocalSocket`：第二次启动发送 `show`，首实例 `showNormal()+raise()+activateWindow()`；失败则继续启动 |
| 任务卡 | `QScrollArea` + `QGridLayout`，列数按宽度切换 1/2/3；`TaskCard` 用 QSS + `paintEvent` 画状态条 |
| 日志 | `QPlainTextEdit`（只读）+ `QTextCharFormat` 按级别着色；`QTextCursor` 追加；自动滚到底；`QSplitter` 调高度 |
| 表单 | `QDialog` + `QLineEdit/QComboBox/QCheckBox/QSpinBox`；依赖成环用弹窗禁用选项 |
| 主题 | 一份 `dark.qss`（深色 + 橙色 accent + 状态色） |
| Sparkline | 自定义 `QWidget::paintEvent` + `QPainter` |
| 刷新 | `QTimer` 250ms 拉快照；按 `task.id/state/updated` 做字段级 diff，只更新变化的卡片 |
| 通知 | 应用内 toast 或 `QSystemTrayIcon::showMessage` |
| 窗口 | **第一版先用系统边框**（稳定）；自定义无边框标题栏放到 M5 之后可选项 |

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| CRLF / 行尾污染 E: 仓库 | 加 `.gitattributes`（`* text=auto`），提交前 `git add --renormalize .`；不要提交纯换行 diff |
| WSL 重启后盘符消失 | `scripts/env.sh` 自动 `mountpoint` 检查并挂载 |
| 代理 IP 变化 | `env.sh` 从 `ip route` 取默认网关，端口 7897 |
| Qt LGPL | 动态链接、随包发 Qt DLL、写 NOTICE；**不静态链接 Qt**（除非改 GPL/商业授权） |
| FFI panic/UB | 每个入口 `catch_unwind`；C++ 侧不跨线程碰 Qt 对象；只用 UTF-8 |
| 4Hz 全量刷新卡顿 | `QTimer` + 字段 diff；日志按行追加，不重建整个控件 |
| Rust 测试在 WSL 跑不了 | 用 Windows `cargo.exe test`（已验证可用） |
| 无人值守卡死 | 单个问题 > 60 分钟即记录并跳下一个独立里程碑；不阻塞等待用户 |
