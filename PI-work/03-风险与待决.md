## 2. 决策门禁（Go / No-Go）

Spike 结束（P1）时，按下表判定。**任何一项红即 No-Go**，不搞「差不多」。

| 门禁 | 通过标准 | 失败即意味着 |
|---|---|---|
| G1 交叉构建 | WSL Docker 产出 exe，Win10/11 双击可启动，无额外 DLL | 发布链路不成立 |
| G2 4Hz 重建 | 12 任务 + 200 行日志：UI 线程 CPU ≤ 2%，输入无可感延迟，无撕裂 | 产品不可用 |
| G3 托盘 | 图标、tooltip、左键恢复、右键菜单（显示/退出）、关闭收起到托盘 | 核心交互缺失 |
| G4 标题栏 | 无边框可拖动、双击最大化、最小化/最大化/关闭、125%/150% DPI 正常 | 窗口体验退化 |
| G5 中文文本 | 真实中文日志无 U+FFFD/乱码；等宽对齐；IME 可输入中文 | 不可接受 |
| G6 单实例 | 二次启动不产生第二窗口，已有窗口恢复并置前 | 守护器语义破坏 |
| G7 主题与自绘 | 深色 token 可配；Canvas sparkline + 三色日志可渲染 | 视觉完全不可控 |
| G8 依赖健康 | `cargo deny`/`cargo audit` 无阻断项；MSRV 明确；许可证清单更新 | 合规/可维护性风险 |

## 3. 需要作者拍板的问题

### 3.0 已确认（2026-10-29）

> **最终决定（2026-10-29 晚）**：改用 **Qt 6 Widgets + Rust 静态库（C ABI）**，ZSUI 不再推进。执行见 `06-Qt-迁移执行计划.md`。

| 编号 | 问题 | 结论 |
|---|---|---|

| D3 | 视觉 | **接受原生质感** + 深色/橙色 accent + 状态色，不做 1:1 还原 |

| D11 | 体积 | **exe ≤ 12 MiB**（目标 3–5 MiB） |
| D12 | 「无子进程」 | **应用自身 0 辅助进程**；被守护任务属于产品语义，不计入 |

### D13 · `data/` 便携目录是否保留？

当前设计是 `<exe 同级>\data\{config.toml, logs\*.log}`，拷走文件夹即用。
如果「单文件」要求连数据都不外露，则需改为 `%LOCALAPPDATA%\TaskWarden\` 或单一数据文件。

- A. 保留便携 `data/`（推荐，与现有行为一致，exe 仍是单文件）

## 4. 我的总体建议（一句话）
