## 1. Spike 门禁（P1）

### 前置：让本机能编译 Rust

当前 WSL **无 cargo**。二选一：

```bash
# 方案 A：本机安装（推荐，后续开发都要用）
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
rustup default stable
rustup target add x86_64-pc-windows-gnu

# 方案 B：Docker（与现有 deploy 流程一致）
docker run --rm -it -v "$PWD":/w -w /w rust:1.89-bookworm bash
#   容器内：apt-get update && apt-get install -y mingw-w64
#           rustup target add x86_64-pc-windows-gnu
```

> ZSUI 官方性能矩阵使用 Rust 1.94；`Cargo.toml` 未声明 `rust-version`。
> 用当前 stable，并在报告里记录实际版本。

### G1 · 交叉构建与单文件

**步骤**

```bash
cargo new --bin spike-zsui && cd spike-zsui
# Cargo.toml 加入 zsui = { version = "=0.3.0-alpha.2", default-features = false,
#   features = ["window", "button", "label", "textbox", "toggle", "tray", "dialog"] }
cargo build --release --target x86_64-pc-windows-gnu
```

**通过标准**

- [ ] 链接成功，产出 `.exe`；
- [ ] 依赖 DLL 检查：`x86_64-w64-mingw32-objdump -p target/.../spike-zsui.exe | grep 'DLL Name'`，除系统 DLL 外无额外文件；
- [ ] 拷贝到干净 Win10/11（无 WebView2、无 VC++ 运行库）双击启动；
- [ ] 窗口可显示、可关闭，无 crash。

**失败处理**：记录完整错误；尝试 `x86_64-pc-windows-msvc`（需 Windows 机）；仍失败 → G1 红。

### G2 · 4Hz 重建性能

**构造**：一个窗口内渲染 12 张任务卡 + 选中任务的 200 行日志，后台线程每 250ms 更新：
- 每张卡的状态、倒计时、探针毫秒、CPU/内存指标；
- 日志每 tick 追加 2 行（模拟 8 行/秒）。

**测量**

- 在 `view()` 与 layout 前后打点，输出 p50/p95 重建耗时；
- Windows 任务管理器 / `Get-Counter` 记录 UI 进程 CPU；
- 人工输入延迟测试：按住窗口拖动、滚动日志、点击按钮。

**通过标准**

- [ ] p95 重建 ≤ 16ms（4Hz 下余量充足）；
- [ ] 平均 CPU ≤ 2%（不含引擎子进程）；
- [ ] 滚动/点击无可感卡顿（主观 + 输入到反馈 ≤ 100ms）；
- [ ] 连续 30 分钟无内存增长（`Get-Process` Private Bytes 漂移 < 5MB）。

- [ ] 确认没有误开 `full` / `all-widgets` / `ui-viewer` 等特性。

**建议 release profile**

```toml

codegen-units = 1

# 不要用 panic = "abort"：supervisor 依赖 catch_unwind
```

### G10 · 进程数（无辅助子进程）

**通过标准**

- [ ] 空闲时任务管理器只有 **1 个 `taskwarden.exe`**（无 WebView2 / msedgewebview2 / conhost 子进程）；
- [ ] 启动/停止/强杀一个任务时，**不出现 `taskkill.exe` 进程**；
- [ ] 被守护任务进程数 = 任务定义数量（用户任务自身派生的孙进程不计）；
- [ ] 托盘隐藏后仍为 1 个进程。

**实现要点**：删除 `runtime/killer.rs` 的 `taskkill`，改 `TerminateJobObject` + `TerminateProcess` 兜底。

## 2. 全量迁移验收（P4）

### 2.1 功能对齐

**命令（15 条）**

- [ ] `list_snapshot` → 首帧即完整
- [ ] `start` / `stop` / `restart`
- [ ] `start_all`（拓扑分层、同层并发）
- [ ] `stop_all`（反拓扑序）
- [ ] `crash`（故障注入）
- [ ] `reset_breaker`
- [ ] `add_task` / `update_task` / `remove_task`
- [ ] `set_fault_inject`
- [ ] `shutdown`（同步终结，所有子进程回收）
- [ ] `get_logs` / `clear_logs`

**语义（`AGENTS.md` §6 的 10 条）逐条打勾**

- [ ] code-0 且存活 < 5s → 计崩溃进熔断
- [ ] `never` → 直接 Stopped 不计数；否则 Backoff(2^n) / Trip
- [ ] Restart 先移交 reaper，`StopDone` 后再启动
- [ ] StopAll 反拓扑；StartAll 分层并发；start 递归启动上游
- [ ] 上游 Stopped 级联停止下游；上游 Fused 只 WARN 不停止
- [ ] 首次派生不计重启（`has_spawned`）
- [ ] 日志环缓冲与事件同源（`emit_log` 单入口）
- [ ] `clear_logs` 只清内存，文件保留
- [ ] shutdown 同步终结
- [ ] 故障注入只影响下一次 spawn，随后自动复位

**UI 行为**

- [ ] 卡片排序（running < starting < backoff < fused < stopped，再按名字）
- [ ] 退避倒计时按秒更新
- [ ] 健康度（tcp/http/ready）与探针毫秒显示
- [ ] 依赖 chip 显示、成环选项禁用
- [ ] 日志自动滚动开关、拖拽调高、双击复位、`localStorage` 持久化
- [ ] 关闭询问：收起到托盘 / 退出
- [ ] 单实例二次启动激活
- [ ] 托盘菜单与 tooltip
